# Scripts do Projeto

## 📂 Estrutura

- **helpers/**: Scripts auxiliares para tarefas repetitivas
- **validation/**: Scripts de validação de cada etapa
- **setup/**: Scripts de setup inicial

## 🎯 Convenções

- Scripts devem ser idempotentes quando possível
- Sempre incluir validação de pré-requisitos
- Usar `set -euo pipefail` para segurança
- Documentar flags e parâmetros no cabeçalho
- Incluir mensagens coloridas para melhor UX
